# Apex 戦術ボード（非公式）

Apex Legends の作戦を、マップ上に実寸で描いて共有するためのブラウザ用戦術ボードです。
インストールは不要で、`index.html` をブラウザで開くか、GitHub Pages の URL にアクセスすれば使えます。

> **これは非公式のファンメイドツールです。**
> Electronic Arts Inc. および Respawn Entertainment とは一切関係がなく、両社の承認・許可・後援も受けていません。

---

## できること

- **マップ**：World's Edge／Storm Point／E-District／Broken Moon。座標はメートル単位で、距離測定とスケール補正ができます。
- **レジェンドのポーン**：全レジェンドを部隊ごとに色分けして配置できます。向き、ダウン状態、射線（ベクトル線）も描けます。
- **スキル**：パッシブ・戦術・アルティメットの効果範囲を実寸で配置できます。形は円・扇形・長方形・壁・矢印など。範囲のデータがないスキルは、アイコンだけを置きます。
- **リング**：現在／次／次の次（リングコンソール）の 3 つの円を置けます。R1〜R6 のテンプレートがあり、手動で収縮させることもできます。
- **ステップ**：盤面をステップごとに保存して、補間アニメーションで再生できます。
- **作戦の保存**：作戦をブラウザに保存できるほか、`.json` ファイルとして書き出し・読み込みできます。

操作方法は、画面左のパネル下部に書いてあります。

## 使い方

- **Web で使う**：GitHub Pages の URL ( https://potstudio0206.github.io/ApexTacboard/ )を開きます。
- **ローカルで使う**：リポジトリをダウンロードし、`index.html` をブラウザで開きます。サーバーは不要です。

作戦などのデータは、使っているブラウザ（の保存領域）に保存されます。ブラウザや URL が変わるとデータは引き継がれないので、残したい作戦は「作戦 ▾」→「ファイルに書き出し」で保存してください。

## 数値について

スキルの範囲・リングの半径・マップの縮尺は、Apex Legends Wiki（wiki.gg）や Liquipedia の情報と、開発者がゲーム内で測った値をもとにしています。
一部の値は推定です（例：Seer のスコープ倍率ごとの距離と角度、スケールが「暫定」のマップ）。ゲームのアップデートで実際と違っている可能性があります。値の出典と推定方法は `skills.json` に書いてあります。
